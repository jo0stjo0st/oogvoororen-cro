# CRO-experimenten

Plaats hier domeinlogica, configuratie en variantcomponenten per experiment, bijvoorbeeld `homepage/variants/variant-a.tsx`.
Maak de bijbehorende App Router-pagina in `src/app/varianten/homepage/a/page.tsx` en importeer daar de variant. Zo heeft elke variant een eigen deelbare URL.
Gedeelde UI hoort in `src/components`; routes en layouts blijven in `src/app`.
